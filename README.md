# قعدة

لعبة ويب عربية بـ HTML وCSS وJavaScript: اختاروا اللعب من موبايل واحد أو غرفة خاصة/أونلاين بكود مشاركة، ثم اختاروا نمط المحتوى من Supabase.

## إعداد Supabase

1. أنشئ مشروعًا في [Supabase](https://supabase.com/).
2. افتح **SQL Editor** وشغّل محتوى `supabase-schema.sql` لإنشاء جدول الأسئلة وسياسة القراءة وإضافة أسئلة البداية.
3. من إعدادات المشروع، انسخ **Project URL** و**publishable key** (أو مفتاح `anon` القديم)، وضعهما في `supabase-config.js`:

   ```js
   export const SUPABASE_URL = "https://ofvfcweuufubywwdlaxp.supabase.co";
   export const SUPABASE_ANON_KEY = "sb_publishable_fO94N1QFPiBwGv_Q2u6hbw_4COAAz7C";
   ```

   المفتاح المنشور مخصص للاستخدام في الواجهة؛ لا تضع `service_role` في ملفات الموقع.
4. شغّل الموقع عبر إضافة **Live Server** في VS Code، أو استخدم خادم Python محليًا إذا كان مثبتًا:

   ```powershell
   python -m http.server 8000
   ```

5. افتح `http://localhost:8000`.

## طريقة اللعب

- اختاروا نمط اللعب المناسب: **موبايل واحد** للعب على نفس الجهاز، **غرفة خاصة / أونلاين** للعب من أجهزة مختلفة بكود الغرفة، **تحدي فريقين**، أو لعبة **مين ده؟**.
- في اللعب من جهاز واحد، أضيفوا اللاعبين واختاروا نمط اللعبة وعدد الجولات (٣ أو ٥ أو ٧ أو ١٠) قبل البدء. يظهر رقم الجولة من إجمالي الجولات، وبعد آخر واحدة تقدروا تبدأوا لعبة جديدة.
- لعبة **مين ده؟** لعبة مستقلة على موبايل واحد: أضيفوا اللاعبين واختاروا الصعوبة وعدد الأدوار. في كل دور، يثبت اللاعب الموبايل على جبهته ويحاول تخمين أكبر عدد خلال ٦٠ ثانية؛ يقرأ أصحابه التلميحات ويضغطون «صح» أو «تخطي»، ثم ينتقل الدور للاعب التالي وتظهر النتيجة في النهاية. اللعبة لا تحتاج اتصالًا بـ Supabase، لكن صور المشاهير تُحمّل من الإنترنت (رابط أحمد حلمي من Arageek وبقية الصور من Wikimedia Commons)؛ تظهر الرسمة التوضيحية إذا تعذر تحميل صورة.
- نمط **تحدي فريقين** يتيح تقسيم لاعبي الجهاز الواحد إلى فريقين بالتناوب، واختيار عدد الجولات؛ تبدأ كل جولة بعجلة تختار بين سؤال عام أو معلومة أو ضحك أو تخمين أو صراحة أو تفكير أو تحدٍ. يمكن كشف الإجابة الصحيحة أو المقترحة، والفريقان يقرران صحة الإجابة ويحتسبان النقاط، والفريق الفائز يسحب تحديًا للفريق الآخر.
- في اللعب أونلاين، يختار صاحب الغرفة عدد الجولات (٣ أو ٥ أو ٧ أو ١٠)، ثم يشارك الكود أو QR لينضم أصحابه. يظهر رقم الجولة من إجمالي الجولات لكل اللاعبين، وتتوقف الجولات الجديدة بعد آخر جولة. زر **انضم إلى غرفة** في اللوبي يفتح إدخال الكود مباشرة.
- تظهر لصاحب الغرفة صورة QR؛ مسحها يفتح صفحة الانضمام والكود معبّأ تلقائيًا.
- أنماط المحتوى: أسئلة عامة، معلومات، أسئلة مضحكة، تخمين أفلام وأغاني بتلميحات أصلية، صراحة، تفكير وخداع، وتحديات. تُسحب البطاقات عشوائيًا من Supabase من غير تكرار قبل استهلاك بطاقات الفئة، ثم تبدأ دورة جديدة. صاحب الغرفة يختار النمط عند إنشائها، ويُطبّق الاختيار على كل اللاعبين.
- موسيقى اللعبة تعمل باستمرار بين مراحل اللعب كصوت خلفية من الملف المحلي `assets/qahwa-background.mp3`، وتبدأ بعد أول ضغطة أو لمسة بسبب قيود التشغيل التلقائي. من زر ⚙ الثابت في كل المراحل يمكن إيقافها أو تعديل مستوى الصوت والثيم، وتُحفظ التفضيلات محليًا. قد يوقفها نظام التشغيل أو المتصفح عند إغلاق الصفحة أو تعليقها.
- صاحب الغرفة وحده يبدأ الجولة ويسحب السؤال التالي ويكشف الإجابة في الغرف المشتركة؛ لا تصل الإجابة لباقي اللاعبين قبل أن يكشفها.
- قائمة اللاعبين والجولات تُرسل مباشرة عبر Supabase Realtime ولا تُحفظ كبيانات دائمة. الغرفة مؤقتة وتنتهي عند مغادرة صاحبها أو انقطاع اتصاله.
- رمز الغرفة ليس نظام حسابات أو صلاحيات؛ شاركوه مع الأشخاص المقصودين فقط. لا تدخلوا بيانات شخصية حساسة.

يحتاج الاتصال بقاعدة الأسئلة لتشغيل الغرف والجولات. شغّل النسخة المحدّثة من `supabase-schema.sql` من **SQL Editor** لتحديث قاعدة قديمة وإضافة فئة «تفكير» وبطاقات الأسئلة الجديدة وإجاباتها؛ السكربت يحوّل فئة «سؤال» القديمة إلى «سؤال عام» ويضيف البطاقات دون تكرار. تلميحات الأغاني تعتمد على أوصاف وإيموجي أصلية، ولا تستخدم مقاطع صوتية أو كلمات أغنيات محمية.
